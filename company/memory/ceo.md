# ceo 팀의 축적된 교훈

## 2026-08-10
- 부서에 업무를 배분할 때 '결정 기준(가중치·수용 불가 조건·충돌 시 tie-breaker)'과 실측 데이터 보유자(상품·생산·물류)에 대한 사전 데이터 요청을 지시서에 먼저 못 박아라 — 오늘은 이 두 가지가 없어서 같은 Qoo10을 두고 부서 간 권고가 정면 충돌하고 재무·운영이 템플릿만 내면서 결정이 하루 밀렸다.

## 2026-08-10
- 증액 기준을 '증분ROAS 1.8 / 공헌이익률 38%'라는 숫자로만 확정하고 산식(플랫폼 수수료·PG·물류·VAT 포함 여부)과 데이터 출처를 정의하지 않아 마케팅과 재무가 서로 다른 게이트표를 만들었으므로, 다음에는 기준을 내릴 때 '지표명 + 산식 + 데이터 출처 + 판정 주체'를 한 줄로 함께 배포한다.

## 2026-08-10
- 목표 매출 30억과 광고비 10억을 동시에 못 박은 결과 영업이익률 20%와 산술적으로 충돌했으므로, 다음에는 목표를 '매출·광고비·이익률' 3개 동시 고정이 아니라 '2개 고정 + 1개 종속' 구조로 제시해 부서가 계산 불가능한 목표를 받지 않게 한다.
