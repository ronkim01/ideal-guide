# 1시간봉 스윙 실패 + 5분봉 재확인 (TradingView Pine Script)

`swing-failure-1h-5m.pine` — 1시간봉에서 스윙 실패(SFP)를 찾고, 5분봉에서 한 번 더 확인한 뒤 들어가는 전략입니다.

## 붙이는 법

1. TradingView → 아래쪽 `Pine 편집기` → 새로 만들기 → 파일 내용 전체 붙여넣기 → `차트에 추가`
2. **5분봉 차트**에 씁니다. 1시간봉 차트에서 쓰려면 설정에서 `5분봉 스윙 실패로 재확인 후 진입`을 끕니다.
3. `전략 테스터` 탭에서 성과를 봅니다. 알림을 걸면 1시간봉 신호와 진입 때 메시지가 옵니다.

## 룰이 코드에서 어떻게 되는지

| 룰 | 코드 |
|---|---|
| 스윙 저점 = 가운데 봉 저점이 앞·뒤 봉보다 낮음 (고점은 반대) | `low[1] < low[2] and low[1] < low` — 세 번째 봉 **마감 후에만** 확정 |
| 전날 스윙까지 찍어두기 | `스윙 유효 기간` 기본 48봉(이틀) 동안 선을 들고 있음 |
| 꼬리로 뚫고 **안에서 마감** = 스윙 실패 | 저점 아래로 꼬리 → 종가가 선 위면 신호. 종가가 선 아래면 돌파로 보고 신호 아님 |
| 마감이 선에서 멀수록 강함 | `마감 강도 최소 (%)` — (종가−선) ÷ 봉 길이 |
| 털린 선은 다시 안 씀 | 한 번 털린(또는 돌파된) 스윙은 목록에서 지움 |
| 다시 그려지지 않음 | 1시간봉 값은 마감된 봉만 사용 (`[1]` + `lookahead_on`) |

### 영상에서 바꾼 세 가지

| 바꾼 것 | 코드 |
|---|---|
| ① 신호 시간 ≠ 진입 시간 | 신호는 언제 나와도 기억해 두고, 진입은 `진입 허용 시간`(기본 런던 08:00–21:00) 안에서만. 신호는 `신호 유효 시간`(기본 12시간) 지나면 버림 |
| ② 5분봉 재확인 | 셋업 뒤에 생긴 5분봉 스윙 저점을 5분봉이 꼬리로 털고 위에서 마감하면 진입. 손절은 그대로 1시간봉 꼬리 밑 → 같은 손절에 거리만 줄어듦 |
| ③ 익절 | 큰 추세(기본 4시간봉 EMA50)와 같은 방향이면 **반대쪽 스윙 끝**, 역추세면 **가장 가까운 스윙(매물대)** 에서 짧게. 해당 스윙이 없으면 고정 손익비 |

그 밖에:

- 손절 위치: `1시간봉 꼬리 밑 (보수)` 기본, `5분봉 꼬리 밑 (공격)` 선택 가능
- 진입 시점 손익비가 `최소 손익비`(기본 1.5) 미만이면 그 눌림은 넘기고 다음 눌림을 기다림 (회색 ×)
- 가격이 1시간봉 꼬리를 넘어 마감하면 "아침 신호 자체가 틀린 것"으로 셋업 취소
- 수량 = 자본 × `1회 손실 한도` ÷ 손절 거리
- 신호가 없으면 아무것도 안 함 — 상태판에 "신호 없음 — 쉬는 날"

## 차트 표시

- 빨강/청록 얇은 선: 1시간봉 최근 스윙 고점/저점
- 주황 선: 털린 스윙선, 회색 선: 셋업 손절 기준(1H 꼬리)
- ▲▼ `1H SFP`: 1시간봉 스윙 실패 신호
- 회색 배경: 진입 금지 시간
- 오른쪽 위 상태판: 대기/보유 상태, 큰 추세, 진입 시간 여부, 손절 기준

## 주의

- 1시간봉 차트에서 쓰면 신호가 한 봉 늦게 반영됩니다(마감 확정값만 쓰기 때문). 5분봉 차트를 권장합니다.
- 백테스트 수수료 기본 0.04%, 슬리피지 1틱. 거래소에 맞게 바꾸세요.
- 매매일지에는 전략 칩 `스윙실패`로 기록하면 전략별 성적에 따로 잡힙니다.
