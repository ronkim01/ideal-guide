# 5. 개선요청 (개발팀 / 운영팀)

> 근거: 위 Top 10 문의 항목 = 고객이 실제로 막히는 지점. 9월 인입 3,000건 기준으로 각 항목의 문의 절감 효과를 추정함.

### 【P0 — 9월 1일 이전 반드시】

**P0-1. 불량 접수 전용 폼 신설** — 개발팀
- **무엇이 문제인가**: 지금은 불량 신고가 카카오채널·DM·플랫폼 문의로 흩어져 들어오고, 사진과 주문번호를 상담원이 되묻는 왕복이 발생한다. 접수 누락 시 집계 자체가 불가능해 **검품 개선의 근거 데이터가 만들어지지 않는다.**
- **왜 문제인가**: 9월 물량이 3월 대비 1.7배. 접수 누락률이 커지면 4번 리포트가 무의미해지고, 불량이 평판 리스크로 커져도 감지가 늦는다.
- **어떻게**: 자사몰 마이페이지 > 주문내역에 **[불량 접수]** 버튼 추가. 필수 입력 = 사진 2장 이상(하자 근접+전체), 하자 부위 선택(코드 S/Z/M/L/C/G/F/O/P/E), 희망 조치(교환·환불·보상). 접수 시 **구글시트/DB에 자동 적재** + 고객에게 접수번호 자동 발송.

**P0-2. 배송 지연 자동 사전 고지** — 개발팀 + 운영팀
- **무엇이 문제인가**: 지연 문의는 전체의 30~40%로 예상되는 최다 문의인데, 고객이 물어봐야 답을 얻는 구조다.
- **왜 문제인가**: 소개팅·하객룩은 **날짜가 곧 제품 가치**다. 지연을 늦게 알수록 취소·악평으로 직결된다.
- **어떻게**: 결제 후 **D+2까지 미출고 건은 알림톡 자동 발송**(템플릿 2-6). "예정일 + 무료 취소 안내" 포함. 사전 고지 시 문의 인입 30% 이상 감소 예상.

**P0-3. 9월 CS 응대 인력·시간 확보** — 운영팀
- **무엇이 문제인가**: 일 평균 110건 / 피크일 350건은 현 인원으로 SLA(카카오 2시간, 플랫폼 24시간) 준수가 불가능하다.
- **왜 문제인가**: 플랫폼 3사는 응답 지연이 **노출 순위·딜 참여 자격에 영향**을 준다. 성수기 딜 성과와 직결.

**P0-4. 로트 정보 추적 체계** — 운영팀
- **무엇이 문제인가**: 불량 접수 시 **어느 생산 로트인지 식별할 수단이 없다.** 원인 규명이 "느낌"에 머문다.

**P1-1. 재입고 알림 신청 기능** — 개발팀
- 품절 문의는 반복 인입되며, 답변해도 고객이 다시 찾아오지 않으면 매출 손실이다. 상품페이지에 **[재입고 알림]** 버튼 + 입고 시 알림톡 자동 발송. 재생산 리드타임 1개월이라 알림 리스트가 곧 **차기 발주 수요 데이터**가 된다.

**P1-3. 교환·반품 진행상태 조회** — 개발팀

# 6. [선제 제출] 일본 CS 운영 요건 1페이지 — Qoo10 Japan 진입 결정 회의 입력값

> 지시받지 않았으나, 채널 결정의 실제 변수이므로 선제 제출한다. **미확정 항목은 "확인 필요"로 명시했다.**

### ① 플랫폼 응답 규정 (검증 필요 항목 포함)
- Qoo10 Japan은 **문의 미응답·배송 지연이 판매자 등급과 노출에 직접 반영**되는 구조. 통상 **문의 24시간 내 응답 / 발송 기한 준수**가 핵심 지표. → **입점 전 정확한 규정 수치와 페널티 기준을 Qoo10 담당 MD로부터 문서로 확보할 것.**
- 메가와리 세일 기간에는 문의가 평시의 수 배로 인입 → **세일 참여 시 응대 인력 사전 확보가 전제 조건**.

### ② 언어·시차
- **시차 없음(한국·일본 동일 시간대)** → 한국 근무시간 그대로 커버 가능. **이것은 대만·중국 대비 명확한 이점.**
- 언어는 병목. 일본어 응대는 **번역기 단독 사용 금지**(정중체 오류가 곧 브랜드 훼손). 대응안 3가지:
  - (a) 표준 스크립트 20종을 원어민 감수로 사전 제작 → 90% 커버, 초기 비용 최소
  - (b) 일본어 가능 파트타임 1명 (주 15시간)
  - (c) 현지 CS 대행 (건당 과금) — 물량 검증 후 검토
  - **권장: 초기 (a) + 예외 건만 (b).**

### ③ 반품 창구 — **가장 큰 미해결 변수**
- 크로스보더 직배송 시 **일본 내 반송 주소가 없으면** 고객이 한국으로 국제 반송해야 하고, 이는 일본 소비자 기준에서 사실상 반품 불가로 인식되어 **리뷰 평점 하락·구매 전환 저하**로 직결된다.
- 선택지:
  1. **일본 내 반송 대행지 확보**(포워더·풀필먼트 창고 계약) — 비용 발생, 신뢰도 최상
  2. **불량 건은 반품 없이 전액 환불 + 제품 회수 면제** — 마리백 원가 32,200원 기준, 국제 회수비(추정 1.5만~2.5만원)와 처리 공수를 감안하면 **회수하지 않는 편이 경제적**. → **1단계 검증 기간에는 이 방식을 권장.**
  3. 단순 변심 반품은 정책상 제한(일본 통신판매는 법정 청약철회가 없어 **판매자 반품 정책 명시가 유효**) — 단, "반품 불가" 표기는 전환율을 떨어뜨리므로 **"초기 불량 7일 내 전액 환불"**을 명확히 표기하는 방향 권장.

### ④ 반품률·불량률 실측 — **현재 데이터 없음**
- 국내 반품률·불량률조차 체계적 실측치가 없다(→ 위 P0-1, 4번 리포트로 9월부터 확보).
- **판단 기준 제안**: 국내 9월 실측 불량률을 기준선으로 잡고, 크로스보더는 **배송 파손(코드 P)이 국내 대비 상승**할 것을 전제로 포장 스펙을 별도 강화. 일본 1단계 목표 지표는 **"불량·파손 접수율 3% 이하, 평점 4.5 이상"**을 제안.

### ⑤ 법적 표기 의무
- 일본 통신판매는 **특정상거래법(特定商取引法)에 근거한 표기**가 필수(판매자명, 소재지, 연락처, 가격·소비세, 배송비, 지불 시기, 반품 조건 등). 누락 시 플랫폼 제재 대상.
