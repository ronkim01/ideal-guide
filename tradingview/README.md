# 스윕 → 구조전환 마감 (TradingView 지표)

> 스윕은 **자리**, 구조 전환 마감은 **신호**. 꼬리로 뚫린 순간이 아니라, 하락을 만든 큰 고점을 **종가로** 넘긴 봉에서 들어간다.

## 설치
1. TradingView → 아래 **Pine 에디터** → 새로 만들기 → `sweep-choch.pine` 내용 전체 붙여넣기 → **차트에 추가**
2. 차트: 골드(XAUUSD) **15분봉**, 차트 시간대 **(UTC+9) 서울**
3. 알림: 알림 추가 → 조건에서 이 지표 → **"alert() 함수 호출만"** 선택

## 차트에 찍히는 것
| 표시 | 뜻 | 할 일 |
|---|---|---|
| 주황 `스윕 전일 저점` | 자리 (손절이 쓸렸다) | 아직 아무것도 안 함 |
| 회색 점선 `작은 전환 — 아직 아님` | 바로 앞 작은 고점만 종가로 넘김 (MSS) | 기다림 — 13일 밤에 털린 자리 |
| 점선(청록/적갈) | 지금 기다리는 **큰 고점** | 이 선 위 종가가 신호 |
| `큰 전환 마감 ✅ LONG` | 큰 고점 종가 돌파 (CHoCH) + 필터 통과 | 진입. 빨강=손절, 초록=익절 |
| `✅ LONG ⚠` | 통과했지만 주의 (아시아·손익비 2 미만) | 사이즈 줄이기 (13일 아침) |
| 회색 `큰 전환 — 패스 ✖` | 전환은 났지만 막힘 (마우스 올리면 이유) | 안 들어감 (14일 낮) |
| `돌파 — ... 밖 마감` | 1H 봉이 레벨 밖에서 마감 | 스윕 아님, 돌파 |

## 규칙 → 코드
| 영상 내용 | 설정 |
|---|---|
| 전일 저점·주간 저점 = 쓸릴 손절이 많은 자리 (A급) | ① 전일/주간 고·저 |
| 오후 몇 시간 동안 생긴 자잘한 저점 = 약한 자리 (B급) | ① 스윙 고·저, ④ B급 막기 |
| 꼬리로 뚫고 안으로 복귀 | ② 레벨 밖 마감 허용 봉 수 |
| 1H가 레벨 아래서 몸통 마감 → 돌파 | ② 돌파 판정 TF = 60 |
| 작은 고점(MSS) vs 떨어지기 시작한 큰 고점(CHoCH) | ③ 스윙 길이 2 / 6 |
| 1H 고점 4,200 → 4,190 → 4,170 = 롱은 역추세 | ④ 큰 봉 방향 TF, 연속 고점 3개 |
| 뉴욕 개장 직전 봉 꼭대기 진입 금지 | ④ 개장전 흔들림 09:00–09:45 (뉴욕 시간) |
| 아시아는 목표가 가까움 | ④ 아시아 세션 (경고만) |
| 손절 = 스윕 꼬리 밑, 익절 = 1.5~2R 또는 전일 고점 | ⑤ 손절/익절 |
| 손익비 1:1.5면 사이즈 줄였어야 | ⑤ 최소 1.5 / 정상 2.0 |

## 통계 표 (영상의 42건 재현)
1H 차트, `전일 고/저` 끄기, `B급` 끄기, `레벨 밖 마감 허용 = 0`(같은 봉 복귀), 기간 90일.
- 스윕 봉에 바로 진입 → 손절률 (영상: 60%)
- 그중 큰 전환 안 나온 건 → 손절률 (영상: 34건 71%)
- 큰 전환까지 나온 건 → (영상: 42건 중 8건)

> ⚠ 같은 봉 안에서 손절·익절이 둘 다 닿으면 손절로 센다(보수적). 숫자는 데이터 공급사(OANDA·FXCM 등)마다 조금씩 다르다.
